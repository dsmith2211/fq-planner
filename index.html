Community Feedback & Issue Tracker

Help improve the FQ Character Planner! Submit feedback, report bugs, or request features. Safe changes are reviewed and implemented automatically overnight. Changes that affect game mechanics require manual review against the rulebook.

Submit Feedback

"Submit via GitHub" opens a pre-filled issue on our tracker (requires a GitHub account). "Copy" formats your feedback for pasting anywhere.

How Feedback Works

1. You submit feedback here or on our GitHub tracker

2. Every night, an automated system reviews new submissions

3. Safe changes (typos, UI fixes, missing data, cost corrections per rulebook) are implemented automatically

4. Mechanics changes (anything that changes how rules work) are flagged for manual review against the FQ rulebook

5. Fixed issues appear in the tracker below with the date resolved

Auto-implementable: Typos, wrong costs, missing skills, UI improvements, display bugs, missing spell names, wrong class restrictions
Requires review: New rules interpretations, homebrew additions, mechanic changes, balance adjustments
